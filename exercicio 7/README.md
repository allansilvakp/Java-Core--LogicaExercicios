# 📝 Exercício 07: Operadores Lógicos Booleanos

## 🎯 Objetivo
Faça um algoritmo que leia dois valores booleanos (lógicos) e determine se ambos são VERDADEIRO ou FALSO.

---

## 💡 Solução Aplicada
*   **Lógica:** Utilização de operadores lógicos relacionais (como `&&` para verificar se ambos são verdadeiros) e validações condicionais correspondentes.
