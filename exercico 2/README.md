# 📝 Exercício 02: Análise de Número

## 🎯 Objetivo
Faça um algoritmo para receber um número qualquer e imprimir na tela se o número é par ou ímpar, positivo ou negativo.

---

## 💡 Solução Aplicada
*   **Processamento:** 
    *   Uso do operador de resto `% 2` para determinar se é par ou ímpar.
    *   Uso de estruturas condicionais (`> 0` e `< 0`) para verificar se o número é positivo ou negativo.
