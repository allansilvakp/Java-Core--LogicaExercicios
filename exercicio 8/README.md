# 📝 Exercício 08: Ordem Decrescente

## 🎯 Objetivo
Faça um algoritmo que leia três valores inteiros diferentes e imprima na tela os valores em ordem decrescente.

---

## 💡 Solução Aplicada
*   **Lógica:** Estruturas condicionais aninhadas de comparação ou algoritmos simples de ordenação para organizar e exibir os três números do maior para o menor.
