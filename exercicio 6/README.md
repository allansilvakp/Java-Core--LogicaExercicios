# 📝 Exercício 06: Reajuste de Valor

## 🎯 Objetivo
Faça um algoritmo que leia um valor qualquer e imprima na tela com um reajuste de 5%.

---

## 💡 Solução Aplicada
*   **Lógica:** Multiplicação do valor lido por `1.05` (ou calculando os 5% e somando ao valor original) para aplicar o aumento.
